🔔 Appointment Reminder (Recall) — English

For doctors, nurses, and front-desk staff.

1. What is this feature?

The Appointment Reminder (also called Recall) lets you plan a future follow-up date for a patient — e.g. "see this patient again in 3 months" — and later run a list of everyone due for a reminder so you can contact them by WhatsApp, SMS, or Twilio.

It is a completely separate feature from the Queue and from Recall Patient (birthday outreach). Setting or viewing reminders never changes today's queue, the working date, or any existing appointment.

2. Where to find it

Entry pointWhereWhat it opens
🔔 Bell buttonConsultation screen, patient banner (next to the phone number, beside the WhatsApp button)Set-Reminder pop-up for the patient currently open
Appt Reminder buttonPatient Directory → each patient row's action buttons (next to Duplicate)Set-Reminder pop-up for that row's patient
🔔 Appt Reminder tabAppointment module → tab strip (next to Recall)The management panel — list, filter, and send reminders in bulk

3. Setting a reminder for one patient

Click the 🔔 bell (Consultation banner) or the Appt Reminder button (Patient Directory row). A pop-up opens with:

  • Mini calendar (top-left) — click any date to select it.
  • Date / Clinic / Doctor / Remarks fields (top-right) — the date field follows your calendar click; Clinic and Doctor default to the current context and can be changed.
  • A grid below showing this patient's existing reminders, with columns Date, Remarks, Clinic, Doctor. Click a row to reload it into the fields above (e.g. to edit or delete it).

At the bottom of the pop-up:

ButtonWhat it does
SaveSaves the date you picked on the calendar, plus Clinic/Doctor/Remarks, as a new reminder row.
1 / 3 / 6 / 9 / 12 MonthOne-click shortcuts — automatically calculates "today + N months" as the date and saves immediately. You do not need to touch the calendar.
DeleteDeletes the reminder row currently selected in the grid (enabled only after you click a row).
ReturnCloses the pop-up.
Tip: You can save more than one reminder for the same patient (e.g. a 3-month AND a 12-month check). Each save adds a new row to the grid — nothing is overwritten.

4. Managing all reminders (the "🔔 Appt Reminder" tab)

Open the Appointment module and click the 🔔 Appt Reminder tab. This is the bulk/management view — it never touches Queue or the working date.

4.1 Filters

FilterPurpose
ClinicShow reminders for one clinic only, or ALL
DoctorShow reminders for one doctor only, or ALL
From / To (date)Reminder due-date range (defaults to next calendar month)
Filter by patient no. (checkbox + range)Only include patients whose patient number falls between the two values

4.2 Viewing results

Click View to load all reminders matching your filters into the Excel-style grid below, with columns: Date, Clinic, Patient, Telephone, Remarks, Status, Contacted.

4.3 Export / Print

ButtonWhat it does
ViewLoads/refreshes the grid using the current filters
ExportDownloads the current grid as an .xls spreadsheet file
PrintOpens a print-ready report of the current grid and sends it to your printer

4.4 Selecting patients and choosing how to contact them

Below the grid: a record count, and All / None buttons to tick or clear every checkbox in the grid at once. You can also tick individual rows one by one.

Choose a contact channel (pick one):

ChannelWhat happens when you send
WhatsAppOpens WhatsApp Web/App with the message pre-filled — you press Send yourself for each patient
SMSOpens your device's SMS app with the message pre-filled
Twilio WhatsAppSends automatically through Twilio using an approved WhatsApp template (choose the template and, optionally, the sending number)
Twilio SMSSends automatically through Twilio SMS using the message box text

The message box supports placeholder chips you can click to insert: {NAME} {FULL_NAME} {CHINESE} {ENGLISH} {CLINIC} {CLINIC_EN} {CLINIC_ZH} {DATE} {DOCTOR} {REMARKS} {PHONE} {PATIENT_NO}. For Twilio WhatsApp, the message box becomes read-only and shows the approved template instead (WhatsApp requires an approved template — free text cannot be sent).

Click Send reminders to start. A one-at-a-time send window appears: it shows the patient's name, phone, and message preview. Click Open/Send to deliver it, Skip to leave that patient's status unchanged, or Next to move on (marks that patient as reminded). This repeats until every selected patient has been handled.

5. One-time setup (IT / Admin only)

Before the feature can save any data, run patient_recalls.sql once in the Supabase SQL Editor for this clinic's project. If you ever see the message "Run patient_recalls.sql in the Supabase SQL editor, then try again", this step has not been done yet.

6. Frequently asked questions

Question / ProblemAnswer
Does this affect the Queue or today's working date?No. This feature only reads/writes its own table and never touches Queue or working-date logic.
"No phone number on the selected row(s)"The patient record has no mobile or phone number on file — add one in Patient Directory first.
"Select a Twilio WhatsApp template..."Open Twilio Setup (button next to the template dropdown) and add/approve a template first.

🔔 覆诊提醒功能 — 简体中文

适用于医生、护士及前台职员。

1. 这是什么功能？

覆诊提醒（Appointment Reminder / Recall）让您为病人预先设定一个未来的覆诊日期 （例如「三个月后再见这位病人」），并可在之后一次过列出所有到期需要提醒的病人， 方便您透过 WhatsApp、短信或 Twilio 联络他们。

此功能与候诊队列（Queue）及生日提醒（Recall Patient）完全独立。 设定或查看覆诊提醒绝不会影响当日候诊队列、工作日期，或任何现有预约。

2. 在哪里可以找到

入口位置打开什么
🔔 铃铛按钮诊症画面的病人横幅（电话号码旁，WhatsApp 按钮旁）为当前病人打开「设定提醒」弹窗
Appt Reminder 按钮病人名册 → 每行病人的操作按钮（「复制到诊所」旁）为该行病人打开「设定提醒」弹窗
🔔 Appt Reminder 分页预约模块 → 分页列（Recall 旁）管理面板 — 批量列表、筛选及发送提醒

3. 为单一病人设定提醒

点击 🔔 铃铛（诊症横幅）或 Appt Reminder 按钮（病人名册行）。会打开一个弹窗，内含：

  • 迷你日历（左上）— 点击任何日期即可选取。
  • 日期／诊所／医生／备注 输入栏（右上）— 日期栏会跟随您在日历上的点击；诊所及医生预设为目前上下文，可自行更改。
  • 下方 表格 显示此病人现有的提醒记录，栏位为 日期、备注、诊所、医生。点击某一行可将其载入上方栏位（例如作编辑或删除）。

弹窗底部按钮：

按钮作用
保存 (Save)将您在日历上选取的日期，连同诊所／医生／备注，保存为新的提醒记录。
1 / 3 / 6 / 9 / 12 个月一键快捷方式 — 自动计算「今天 + N 个月」作为日期并立即保存，无需操作日历。
删除 (Delete)删除表格中目前选中的提醒记录（需先点击某一行才会启用）。
返回 (Return)关闭弹窗。
提示：同一位病人可以保存多笔提醒（例如同时设定 3 个月及 12 个月覆诊）。每次保存都会新增一行，不会覆盖之前的记录。

4. 管理所有提醒（「🔔 Appt Reminder」分页）

打开预约模块，点击 🔔 Appt Reminder 分页。此为批量管理画面， 绝不会影响候诊队列或工作日期。

4.1 筛选条件

筛选用途
诊所只显示某一诊所的提醒，或选「全部」
医生只显示某一医生的提醒，或选「全部」
由 / 至（日期）提醒到期日期范围（预设为下一个日历月）
按病历号筛选（勾选框＋范围）只包含病历号介于所设范围内的病人

4.2 查看结果

点击 查看 (View)，即可将符合筛选条件的所有提醒载入下方的 Excel 式表格， 栏位为：日期、诊所、病人、电话、备注、状态、已联络。

4.3 导出／列印

按钮作用
查看 (View)按目前筛选条件载入／刷新表格
导出 (Export)将目前表格下载为 .xls 试算表文件
列印 (Print)打开目前表格的可列印报表并送到您的打印机

4.4 选取病人及选择联络方式

表格下方显示记录数目，以及 全选 / 全不选 按钮，可一次勾选或清除表格内所有勾选框， 亦可逐行个别勾选。

选择一种联络方式（择一）：

方式发送时会发生什么
WhatsApp打开 WhatsApp 网页版／应用程式并预先填入讯息 — 每位病人需您自行按下发送
短信 (SMS)打开您装置的短信应用程式并预先填入讯息
Twilio WhatsApp透过 Twilio 使用已核准的 WhatsApp 模板自动发送（可选择模板及发送号码）
Twilio 短信透过 Twilio 短信服务，使用讯息框内的文字自动发送

讯息输入框支援点击插入的占位符： {NAME} {FULL_NAME} {CHINESE} {ENGLISH} {CLINIC} {CLINIC_EN} {CLINIC_ZH} {DATE} {DOCTOR} {REMARKS} {PHONE} {PATIENT_NO}。 使用 Twilio WhatsApp 时，讯息框会变为只读，改为显示已核准的模板内容 （WhatsApp 规定必须使用已核准模板，不能发送自由文字）。

点击 发送提醒 开始发送。系统会逐位显示发送窗口，列出病人姓名、电话及讯息预览。 点击 打开／发送 即发送该讯息，跳过 则不改变该病人状态， 下一位 会将该病人标记为「已提醒」并继续下一位，直至所有已选病人处理完毕。

5. 一次性设置（仅限 IT／管理员）

使用此功能前，须在此诊所的 Supabase SQL 编辑器 执行一次 patient_recalls.sql。如看到讯息 「请先在 Supabase SQL 编辑器运行 patient_recalls.sql」，即表示尚未执行此步骤。

6. 常见问题

问题解答
会否影响候诊队列或今日工作日期？不会。此功能只读写自己独立的数据表，绝不会碰到候诊队列或工作日期逻辑。
「所选行没有电话号码」该病人档案未有登记手机或电话号码 — 请先到病人名册补登。
「请选择 Twilio WhatsApp 模板…」请先点击模板下拉选单旁的 Twilio 设置 按钮，新增并核准模板。
列表中看不到某笔提醒请检查诊所／医生／日期筛选条件 — 只有状态为「待覆诊」或「已提醒」，且日期落在所选范围内的记录才会显示。
可否为同一病人设定多笔提醒？可以 — 每次按「保存」或月份按钮都会新增一行，不会覆盖先前记录。

🔔 覆診提醒功能 — 繁體中文

適用於醫生、護士及前台職員。

1. 這是什麼功能？

覆診提醒（Appointment Reminder / Recall）讓您為病人預先設定一個未來的覆診日期 （例如「三個月後再見這位病人」），並可在之後一次過列出所有到期需要提醒的病人， 方便您透過 WhatsApp、短訊或 Twilio 聯絡他們。

此功能與候診隊列（Queue）及生日提醒（Recall Patient）完全獨立。 設定或查看覆診提醒絕不會影響當日候診隊列、工作日期，或任何現有預約。

2. 在哪裡可以找到

入口位置打開什麼
🔔 鈴鐺按鈕診症畫面的病人橫幅（電話號碼旁，WhatsApp 按鈕旁）為目前病人打開「設定提醒」彈窗
Appt Reminder 按鈕病人名冊 → 每行病人的操作按鈕（「複製到診所」旁）為該行病人打開「設定提醒」彈窗
🔔 Appt Reminder 分頁預約模組 → 分頁列（Recall 旁）管理面板 — 批量列表、篩選及發送提醒

3. 為單一病人設定提醒

點擊 🔔 鈴鐺（診症橫幅）或 Appt Reminder 按鈕（病人名冊行）。會打開一個彈窗，內含：

  • 迷你日曆（左上）— 點擊任何日期即可選取。
  • 日期／診所／醫生／備註 輸入欄（右上）— 日期欄會跟隨您在日曆上的點擊；診所及醫生預設為目前上下文，可自行更改。
  • 下方 表格 顯示此病人現有的提醒紀錄，欄位為 日期、備註、診所、醫生。點擊某一行可將其載入上方欄位（例如作編輯或刪除）。

彈窗底部按鈕：

按鈕作用
儲存 (Save)將您在日曆上選取的日期，連同診所／醫生／備註，儲存為新的提醒紀錄。
1 / 3 / 6 / 9 / 12 個月一鍵快捷方式 — 自動計算「今天 + N 個月」作為日期並立即儲存，無需操作日曆。
刪除 (Delete)刪除表格中目前選中的提醒紀錄（需先點擊某一行才會啟用）。
返回 (Return)關閉彈窗。
提示：同一位病人可以儲存多筆提醒（例如同時設定 3 個月及 12 個月覆診）。每次儲存都會新增一行，不會覆蓋之前的紀錄。

4. 管理所有提醒（「🔔 Appt Reminder」分頁）

打開預約模組，點擊 🔔 Appt Reminder 分頁。此為批量管理畫面， 絕不會影響候診隊列或工作日期。

4.1 篩選條件

篩選用途
診所只顯示某一診所的提醒，或選「全部」
醫生只顯示某一醫生的提醒，或選「全部」
由 / 至（日期）提醒到期日期範圍（預設為下一個日曆月）
按病歷號篩選（勾選框＋範圍）只包含病歷號介於所設範圍內的病人

4.2 查看結果

點擊 查看 (View)，即可將符合篩選條件的所有提醒載入下方的 Excel 式表格， 欄位為：日期、診所、病人、電話、備註、狀態、已聯絡。

4.3 匯出／列印

按鈕作用
查看 (View)按目前篩選條件載入／重新整理表格
匯出 (Export)將目前表格下載為 .xls 試算表檔案
列印 (Print)打開目前表格的可列印報表並送到您的印表機

4.4 選取病人及選擇聯絡方式

表格下方顯示紀錄數目，以及 全選 / 全不選 按鈕，可一次勾選或清除表格內所有勾選框， 亦可逐行個別勾選。

選擇一種聯絡方式（擇一）：

方式發送時會發生什麼
WhatsApp打開 WhatsApp 網頁版／應用程式並預先填入訊息 — 每位病人需您自行按下發送
短訊 (SMS)打開您裝置的短訊應用程式並預先填入訊息
Twilio WhatsApp透過 Twilio 使用已核准的 WhatsApp 範本自動發送（可選擇範本及發送號碼）
Twilio 短訊透過 Twilio 短訊服務，使用訊息框內的文字自動發送

訊息輸入框支援點擊插入的佔位符： {NAME} {FULL_NAME} {CHINESE} {ENGLISH} {CLINIC} {CLINIC_EN} {CLINIC_ZH} {DATE} {DOCTOR} {REMARKS} {PHONE} {PATIENT_NO}。 使用 Twilio WhatsApp 時，訊息框會變為唯讀，改為顯示已核准的範本內容 （WhatsApp 規定必須使用已核准範本，不能發送自由文字）。

點擊 發送提醒 開始發送。系統會逐位顯示發送視窗，列出病人姓名、電話及訊息預覽。 點擊 開啟／發送 即發送該訊息，跳過 則不改變該病人狀態， 下一位 會將該病人標記為「已提醒」並繼續下一位，直至所有已選病人處理完畢。

5. 一次性設置（僅限 IT／管理員）

使用此功能前，須在此診所的 Supabase SQL 編輯器 執行一次 patient_recalls.sql。如看到訊息 「請先在 Supabase SQL 編輯器執行 patient_recalls.sql」，即表示尚未執行此步驟。
