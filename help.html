0 Start here

Log in → pick module from dashboard → choose clinic at top of Appointment screen.

EnglishSign in with your clinic account. On the dashboard, tap 📅 Appointment for front-desk work, or 🩺 Consultation for clinical notes, drugs, and X-rays.
繁體中文使用診所帳號登入。主頁按 📅 Appointment（預約） 做前台；按 🩺 Consultation（診症） 寫病歷、開藥、上載 X 光。
Login→ Dashboard→ Appointment / Consultation

1 Make appointment

Book a new slot: patient + doctor + time.

English
繁體中文
  1. Dashboard → 📅 Appointment 主頁 → 預約
  2. Top bar: select Clinic (correct branch) 選擇診所
  3. Tab: ➕ Appointment 「➕ 預約」分頁
  4. Search patient → pick from list 搜尋病人 → 點選
  5. Choose Doctor — timeline appears 選醫生 → 顯示時間線
  6. Tap an empty slot on the timeline → fill date/time/details → Save 點空白時段 → 填資料 → 儲存
Walk-in with no record? Register in Patient module first. 無病人檔？先在 Patient 登記。

2 Change / reschedule booking

Move time, edit details, or cancel — without losing the patient link.

  1. ➕ Appointment → find the patient’s card on the timeline 在時間線找到預約卡
  2. Drag the card to a new slot or double-click → Edit appointment 拖曳改時段 · 或雙擊編輯
  3. Change date, time, doctor, remarks → Save 改日期/時間/醫生/備註 → 儲存
  4. Optional: use Calendar tab for month view 可用「月曆」分頁總覽
Drag = fastest reschedule 拖曳 = 最快改期

3 Check in → put patient in queue

Today’s list → Check In → patient appears in Current Queue.

Today tab→ Check In→ Current Queue
  1. 📅 Appointment → tab Today 預約 →「今日」
  2. Find the patient row → click Check In → confirm 按「簽到」→ 確認
  3. Switch to tab Current Queue — patient is listed 「候診」分頁 — 病人已入隊
  4. Type in Treatment column if needed (auto-saves when you leave the field) 「治療」欄可輸入，離開欄位自動儲存
Walk-in: use New Patient on Today tab, then Check In.

4 Queue — while patient is waiting

Reorder, open notes, bill, or send doctor to consultation.

  1. Tab Current Queue — filter doctors if needed 「候診」— 可按醫生篩選
  2. Drag rows to change order (saved automatically) 拖曳改順序（自動儲存）
  3. Actions ▾ menu per row: 每行「操作 ▾」： · Clinical Notes → Consultation
    · Open Bill → Billing
    · Edit remarks (📝 icon)
  4. Double-click row → quick patient / appointment actions 雙擊列 → 快捷功能

5 Finish patient (visit complete)

After treatment and billing — remove from active queue.

  1. In Current Queue → Actions ▾ 候診 → 操作
  2. Choose Mark Done 選「標記完成」
  3. Patient leaves the queue (history stays in Today / Records) 離開候診（紀錄仍在今日/紀錄）
Did not arrive? Use No Show instead. 未到？用「標記未到」。

6 Doctor — treatment notes

Write and save clinical notes for the active patient.

  1. Dashboard → 🩺 Consultation 主頁 → 診症
  2. Search patient name / number → select 搜尋病人 → 選取
  3. Left panel: Treatment tab (default) 左側「治療」分頁
  4. Type in the note box → 💾 Save Note 輸入內容 →「💾 儲存記錄」
  5. Notes appear in the timeline below (newest on top) 記錄顯示於下方時間軸
Templates: Save template / From template buttons above the box. From queue: Actions → Clinical Notes opens same screen.

7 Doctor — prescribe drugs

Build prescription line by line; quantity fills after you pick days.

  1. Same patient in Consultation → right panel 診症 → 右側藥物欄
  2. Click + Add Drug 「+ 新增藥物」
  3. -- Select Drug -- — dose & frequency load from Drug Book 選藥物 — 劑量/次數從藥物手冊載入
  4. Choose Days * — quantity calculates automatically 選「天數 *」— 數量自動計算
  5. Click ✓ Add to list on the line (repeat for more drugs) 按「✓ 加入清單」— 可加多種藥
  6. When finished → 💾 Save Prescription 完成 →「💾 儲存處方」
  7. Print labels: 🖨 EN or 🖨 中文 on saved Rx 列印標籤：英文 / 中文
Quantity shows “—”? Select Days first, then Add to list. If still wrong, tell admin the drug name (dose text in Drug Book).
數量顯示「—」？ 先選天數，再加入清單。

8 Upload X-ray to cloud (Supabase)

Store images in the clinic cloud bucket — linked to the patient record.

  1. Consultation → search & select patient 診症 → 選病人
  2. Sub-tab: X-Rays 「X 光」分頁
  3. Click 📤 Upload X-Ray → choose file(s) (JPG, PNG, DICOM…) 「📤 上載 X 光片」→ 選檔
  4. If prompted: set type, date, notes → confirm 填類型/日期/備註 → 確認
  5. Wait for progress bar → Done — thumbnail appears in gallery 等候上載完成 → 圖片出現在畫廊
EnglishFiles are stored securely in the cloud (Supabase storage). Only staff logged into the clinic system can upload. Do not share patient images outside the app.
繁體中文檔案儲存於雲端（Supabase）。只有登入系統的職員可上載。請勿把病人影像傳到系統以外。

9 Billing

Open bill from queue or consultation; save and print receipt.

  1. From queue: Actions ▾ → Open Bill 候診 → 操作 →「開啟帳單」
  2. From consultation: top Bill button (after patient selected) 診症頂部「帳單」按鈕
  3. Add items / adjust amounts → Save bill 加入項目 / 改金額 → 儲存帳單
  4. Record payment → print receipt if needed 記錄付款 → 列印收據
Outstanding balance may show on the patient banner in Consultation.

! If something goes wrong

English
  • Press F5 (refresh) once.
  • Re-open the patient or appointment screen.
  • Report: your user ID, patient number, time, screenshot.
繁體中文
  • 先按 F5 重新整理一次。
  • 重新開啟病人或預約畫面。
  • 回報：帳號、病人編號、時間、截圖。
Not available in pre-test: Expenses, Inventory (disabled). Configuration = admin only.
預試未開放： Expenses、Inventory。Configuration 僅管理員。
